Upload your filled-in sheet

Accepts .xlsx or .csv. Only rows with a Counted Qty filled in are applied — leave a row blank to skip it. Uploading again for a product already in this count overwrites its counted quantity.

{% if shelves %} {% endif %}

Never overwrites a shelf a product already has — only fills in the ones that don't have one yet. Handy for the exact case where you're counting one physical area (Back Store, a warehouse rack…) and finding items that were never assigned there in the system.

Columns: Barcode, Product Name (required), Rename To, Unit, System Qty, Counted Qty. Each row is matched to a product by Barcode first, falling back to an exact Product Name match if the barcode is blank. A row that matches nothing becomes an error instead of silently being skipped.

Rename To is optional — fill it in only for a row where you want to fix the product's name (a typo, a naming-convention correction) while you're already looking right at it during the count. Leave it blank to leave the name alone. It's ignored entirely on an older sheet downloaded before this column existed — nothing breaks if you upload one of those.

Counted Qty is in the product's base unit — the one shown in the Unit column. It replaces whatever this session already has for that product, same as typing a new number into the Counted field by hand. This doesn't touch stock until the count is completed.

Products sold in more than one unit get an extra column per unit (e.g. Sack, Elf Load), shaded green. Count 2 sacks and 3 loose kilos by writing 2 under Sack and 3 under Counted Qty — the import converts and adds them up for you (2 × 25 + 3 = 53 Kg), so nobody has to do the multiplication by hand. A — means that unit doesn't apply to that product; leave it alone.
