Upload your filled-in file

Accepts .xlsx or .csv. Each row adds one unit to a product's ladder — use several rows with the same Product Name to build up a full ladder for one item.

This import is for the extra selling units only — the product itself must already exist (add it first with the Normal products import or the Add Product form). Uploading a product's units here replaces its whole ladder with what's in the file, so include every unit that product should have, not just the new one.

Columns: Product Name (must match an existing product), Unit Name, Equivalent Qty, Of Unit (optional — leave blank to mean "relative to the product's base unit", or name another unit already in the same file to chain it, e.g. Elf Load = 6 × Sack), Fixed Price, Markup %, Margin %.

Example: GRAVEL's base unit is Kg. One row says "Sack = 25 Kg" at ₱500 fixed. A second row says "Elf Load = 6, of Sack" at ₱30,000 fixed — that's 6 sacks (150 kg) per Elf Load.
